# Texture credits

Photographic surface detail is derived from **Poly Haven** texture sets, released under
**CC0** (public domain): https://polyhaven.com/license

| File prefix | Source set | Author |
| --- | --- | --- |
| `regolith_*` | [Gravelly Sand](https://polyhaven.com/a/gravelly_sand) | Poly Haven |
| `bedrock_*` | [Rock Face 03](https://polyhaven.com/a/rock_face_03) | Poly Haven |
| `strata_*` | [Cliff Side](https://polyhaven.com/a/cliff_side) | Poly Haven |

The 1k originals (diffuse, OpenGL normal, roughness) were packed by
`scripts/process_textures.py` into a linear "detail ratio" map (Mars hue comes from the terrain's
vertex colours) and a normal-XY + roughness map, at 1024 and 512 px.
