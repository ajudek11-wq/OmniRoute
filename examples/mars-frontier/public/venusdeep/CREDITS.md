# Venus / Deep Space texture credits

Photographic detail textures from **Poly Haven**, released under **CC0** (public domain):
https://polyhaven.com/license

| File | Source set | Processing |
| --- | --- | --- |
| `soil_diff.jpg`, `soil_nor.jpg` | [Dry Ground Rocks](https://polyhaven.com/a/dry_ground_rocks) | diffuse converted to greyscale + auto-contrast (tinted to basalt in the shader) |
| `basalt_diff.jpg`, `basalt_nor.jpg` | [Rock Boulder Dry](https://polyhaven.com/a/rock_boulder_dry) | diffuse converted to greyscale + auto-contrast |

Everything else in the Venus and Deep Space worlds (clouds, lensing, nebula, pulsar, galaxies) is
procedural. The far cloud sphere uses `public/planets/venus_atmos_*` (Solar System Scope, CC BY 4.0).
